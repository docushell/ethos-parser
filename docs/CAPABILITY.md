# What this engine can and cannot do

**Version in this file, not in its name:** these two tables describe **0.36.2**. When the workspace
version moves, this page moves with it or it is wrong.

This is the honest inventory, for the question *"what does ethos-engine actually do today?"* It is
not the north star (`00-NORTH-STAR.md`), not the roadmap (`02-ROADMAP.md`), and not a claim.
Anything not in the **Can** table is not something to promise.

---

## Can

Everything below runs locally, in this tree, with no network and no renderer.

| Area | What works | Where |
| --- | --- | --- |
| **Classify** | A PDF is classified into reason codes on two orthogonal axes (OCR-need, layout-hard), with per-page counts and three distinct exit codes. No confidence float anywhere | `engine classify` |
| **Extract (PDF)** | A born-digital PDF's text runs, each with a `NativeLocator` back into the source bytes, and an ink box only where font metrics measured one | `engine extract` |
| **Grounding emit** | `ethos.grounding.v1` — **for PDF only**. `source.media_type` is a `const` of `application/pdf` in the schema, and the projector refuses anything else by name | `engine ground` |
| **Grounding check** | A validator that agrees byte-identically with `ethos grounding check` on `structure`, `source_binding`, `representation_sha256` and `counts`. The corpus is 15 Ethos-owned fixtures; **12 reach an artifact and are compared** (`ORACLE_AGREED_COUNT`), and the rest fail closed rather than being skipped | `engine grounding-check` |
| **Markdown / HTML** | `ethos.markdown.v1` and `ethos.html.v1`, **each carrying its Anchor Map** — every byte is `source` or `syntax`, with a coverage census for what did not make it. Projected from **the representation**, so an office representation projects too — measured: `engine markdown` on a DOCX artifact exits 0 with a full map. It was designed and tested against PDF; the office path is unexercised, not refused | `engine markdown`, `engine html` |
| **Verify** | Shells out to the Ethos CLI as a *declared capability*, relaying its bytes verbatim, with the verifier pinned in the profile. The engine does not verify anything itself | `engine verify` |
| **Fuzzing** | **Three `cargo-fuzz` targets**: `open_and_classify` and `open_and_extract` on the PDF entry points (v0-M7), and `office_read` on `engine_office::read` (v2-S12), which one measured campaign showed reaches **all eight** office readers from a corpus seeded with the sixteen packages in `fixtures/office/`. The v2-S12 campaign ran **3,808,191 executions over ~57 minutes** under AddressSanitizer and debug assertions and **found nothing**. **Anydoc's A11 is closed on both lanes since v2-S13**: `crates/engine-office/tests/robustness.rs` damages every one of the sixteen packages in `fixtures/office/` twelve ways — 148 mutants, no panic, 36 survivors pinned in five explained classes — so mutation now covers both corpora, as `docs/06-STEAL-REFUSE.md`'s A11 row says. This cell claimed the office half was *"still open"* and that *"no office fixture has been mutated"* for one slice after it stopped being true, contradicting that row; repaired at v2-S13.3 | `fuzz/` |
| **Overlay** | An annotated PDF showing what was detected — including what has **no** box | `engine overlay` |
| **Adapters** | MCP over stdio (`extract`, `ground`, `node_get`), a Python SDK, a Node SDK, and LangChain tools over both. The engine **mints** every locator, hands it back **opaque**, and **re-validates** it on the way in. No adapter takes a geometry keyword argument | `engine mcp`, `packages/python`, `packages/node` |
| **Extract (office)** | **DOCX, XLSX, PPTX, ODT, ODS, ODP, RTF, EPUB** into the same representation, with **structural** locators, every field a thing the file contains — `{part, paragraph, run}`, `{part, sheet, row, column}`, `{part, shape, paragraph, run}`, `{part, paragraph}`, `{part, table, row, column}`, `{part, draw_page, shape, paragraph}`, `{paragraph}`, `{part, block}`. Each is `deny_unknown_fields`. The ODS row and column are **positions**, because OpenDocument writes no address at all; so is the ODP draw page, which is named for the `<draw:page>` element rather than for the page it resembles. **RTF names no part at all**, because it has none; an EPUB's part is the spine document the package names, **never the entry the archive stored first** — see `15-V2-MILESTONES.md` S6 through S9 | `engine extract` |
| **Office pages** | **`pages: []`, always.** No office format synthesises a page — not a spreadsheet's print range, not a slide, not an ODT's or an ODS's `<text:soft-page-break/>`, not a `<draw:page>` with a master page's `fo:page-width` beside it, which is the one case where a `PageRecord` needed no arithmetic at all, not RTF's `\page`, which says the word outright, and **not an EPUB navigation document's `page-list`, which really does name the pages of a print edition** — a publisher's label about somebody else's paper has no width and no height, so nothing could ever be validated against it (row **L30**) | — |
| **Office names** | Where a file writes a name a person recognises — a sheet, a table, a draw page, a shape — it is carried **verbatim with entities resolved**. A name that could not be measured unique is on the **attributes**, never in the address: `<p:cNvPr id>` was measured across 18 real decks and is not, and ODF's optional `draw:name` was never measurable at all | `engine extract` |
| **Office embedded assets** | **Counted, never read** (v2-S11). Every one of the eight readers declares how many entries it passed over that hold a picture, an audio or video clip, or an embedded object. The three OOXML readers say so under their own code — `office-embedded-parts-not-read`, separate from `office-parts-not-read` because that one's message says its parts *carry text* and a PNG does not; ODT, ODS, ODP, RTF and EPUB already folded theirs into their single bucket, whose prose already named *"pictures or an embedded object"*. **No byte is decoded, measured or fingerprinted, and no node is emitted**: a media part has no text, no address a citation could bind to and no geometry. A media part is identified by **where the package puts it** — `word/media/` and `word/embeddings/`, `xl/media/` and `xl/embeddings/`, `ppt/media/` and `ppt/embeddings/` — which the package itself states, never by sniffing bytes and never by an extension (**A4**) | `engine extract` |
| **Office grounding** | `engine ground` on an office artifact is a **named refusal** naming `application/pdf` and the law. It fails closed with empty stdout and exit 2 | `engine ground` |
| **Bytes that state no format** | Refused by naming what was **looked for** — a ZIP local file header, an RTF brace group, a PDF header — and naming **no format that was not measured**. A `.csv`, a letter and a log line get **byte-identical** stderr, which is the assertion that nothing sniffed. No file name is read and no signature is looked for past byte 0. A **truncated** PDF keeps the PDF reader's own message, because it aimed there (v2-S10) | `engine extract` |
| **Tables** | The row/column + span **model**, `CellSlot` occupancy, three named detection rules (`ruled-rects-v3`, `unruled-align-v1`, `stroke-ruled-v1`), and the geometric↔structural **cross-check**. Its disagreements go on the artifact — and since v2-S20 a **structural** disagreement makes the ruled rule refuse the grid rather than emit it, because the Markdown and HTML projections draw every table the artifact carries and consult no check. The refusal is declared, with its page and its fault counts | `engine extract` |
| **Fabrication** | **0** on the twelve-PDF labelled set — measured every run, not asserted | `table-gate-v1.md` |
| **Table accuracy** | Macro cell-slot **F1 = 70‰** on those twelve documents (64‰ on the four measured before v2-S19), by a method stated completely enough to recompute. **Read the band with it: 0‰..590‰, median 0‰, nine of twelve score exactly 0‰** — the detector emits no table at all on them, so the macro describes which documents have drawn rules more than it describes the engine | `table-gate-v1.md` |
| **Determinism** | Two runs over one document produce identical bytes, across every format | CI |

## Cannot

Some of these are *not yet*; some are **refusals** that no version reverses. The column says which.

| Claim | Kind | Why |
| --- | --- | --- |
| **"v1 is complete"** | not yet | S7 is open. The table number is measured and missed at **70‰ over twelve documents**, the **> 0.489 chase is parked, which is not a pass** (`00-NORTH-STAR.md` #10), and decision **#18** that would close v1 is **written and undecided** |
| **"v2 is complete"** | **gate met; no question open** | S0 through S15 are done and **v2's format row is closed** — eight formats read, one argued refusal, every split against a measurement. **Both questions that stood between this repository and the gate were settled by the owner on 2026-08-21**, as `00-NORTH-STAR.md` decisions **#16** and **#17**. **#16 — *ground* means *bind*:** a DOCX quote and an XLSX cell each resolve to an address the file itself states, which the eight readers emit and have since v2-S3. The literal reading — emit `ethos.grounding.v1` — is refused by the schema and contradicted by the gate's own second half, since grounding requires pages and *"no synthesised pages"* is the same sentence. Option (a), widening the verifier's schema, remains **blocked on an Ethos-side revision owned elsewhere** rather than refused. **#17 — embedded assets *counted* satisfies v2:** every reader declares how many entries it passed over that hold a picture, clip or embedded object, which is what **A14** requires. Reading one is explicitly not v2 — an office image has no page and no coordinate system, so a node for it is a contract change — and it gets its own row rather than sitting implied inside v2's. **`zip.rs`'s CRC-32 is now verified** (`15-V2-MILESTONES.md` S14, 0.33.0). It was the last open question: a corrupted part that still inflated to its declared length was read as though intact. `read_entry` now compares the CRC-32 the central directory carries and refuses a mismatch as `Malformed { what: "ooxml part checksum" }`, named distinctly from a length or signature failure. It shipped on a measurement rather than a preference — **zero false refusals across 40 valid packages and 2,370 entries** — and the office mutation harness recorded it as survivors falling 36 to 31, emptying the `main-part-byte-flipped` class entirely. **No question stands.** **v2-S13.5** ran the two sweeps v2-S13.3 left unrun and repaired eighteen statements that had stopped being true — including `07-VERIFY-BOUNDARY.md` holding fourteen of this repository's seventeen forced decisions while claiming to hold them *verbatim, identically*. It named two clusters and repaired neither. **v2-S14.1 (0.33.1) wrote the two guards S13.5 found named in doc comments and never written** — cell text is now asserted to survive the multi-column reorder, and the xref repair id to be the same string on both sides of the crate boundary — and repaired the **`four words`** cluster at its four live sites, leaving the two inside frozen history named rather than rewritten. **`neither detector` — fifteen sites — moved as one at 0.34.0** by **v2-S15**, comments and wire strings together, because repairing the comments alone would have left the wire saying *neither* and the comments saying otherwise. The new wording carries **no ordinal** — *no detector reads `/TH`* — so a fourth detector cannot re-rot it. It is a **minor**: an artifact this build emits differs from one 0.33.1 emitted for the same bytes, and the blast radius was measured before the wording was chosen — `representation_sha256` moves, `profile_sha256` does not, the Ethos oracle does not, and neither mutation harness does |
| **Beating 0.489, or quoting it as this engine's score** | **refusal** | 0.489 is a published ODL-local score on **their** corpus; 70‰ is this engine on **twelve tagged PDFs this repository owns**. Same unit, different exam. It is never published as ours, and it is no longer chased |
| **OCR, or a scan read as `Extracted`** | not yet — **v4**, under its own profile | Recognition is a different derivation class and a different trust ladder. An OCR fingerprint must be provably incomparable with a born-digital parse before the lane exists |
| **Wrapping LiteParse, OpenDataLoader, Anydoc or pdf-inspector as the grounded PDF core** | **refusal** | Reference-only, and their ideas are taken rather than their code (`06-STEAL-REFUSE.md`). The measured LiteParse adapter was **refused** and is pinned by a test |
| **LibreOffice → PDF for office formats** | **refusal** | **It invents pagination.** Pagination does not exist in a DOCX and must not be synthesised. Not a fallback, not behind a flag (row **L30**) |
| **Grounding a DOCX quote as `ethos.grounding.v1`** | **decided at v2-S1**, option (b): the schema stays PDF-only | Three walls — `source.media_type` is a `const` of `application/pdf`, every element requires a `page`, every page requires integer geometry. Widening the engine's copy would be a change to the **verifier's** contract, which `07-VERIFY-BOUNDARY.md` forbids making here; option (a) is **blocked on an Ethos-side revision, owned elsewhere rather than refused**. Pinned by `engine-grounding/tests/page_less_source.rs` (`14-V2-SCOPE.md` §5) |
| **CSV** | **refusal at v2-S10, with named reopening preconditions** | Not because a CSV parse would fabricate content — **it would not**. Every field's text would be bytes genuinely present, every record ordinal a true line count, and `pages: []` simply true. **Exactly one field would be false:** `SourceIdentity.media_type` would say `text/csv` about a file nobody measured to be one, and `SourceIdentity` is `deny_unknown_fields` with two fields and **no room to say "asserted"** — so a caller-supplied `--format csv` would not break **A4**'s rule but its **guarantee**, with nowhere to record that it had (`13-V12-MILESTONES.md`, v1.2-S5: *an identity that can be asserted is an identity that can disagree with what it describes*). And the engine could never tell a wrong assertion from a right one, so fail-closed is unreachable from inside that design. What S10 shipped instead is the **refusal**: a `.csv` is no longer told it lacks a `%PDF-` header, and a `.csv` and a letter containing a shopping list get **byte-identical** stderr — the test only an implementation that sniffed nothing can pass. **Reopens on either:** (1) `SourceIdentity` can record asserted-vs-measured, which is a `REPRESENTATION_SCHEMA_VERSION` move and a **contract slice with its own scope doc**; or (2) a measured predicate with a **measured false-positive rate**, on a real corpus of prose and real-world CSV, stated the way `table-gate-v1.md` states its table number. Neither is met, neither is a day's work, and neither was started |
| **EPUB CSS, scripts, media overlays, SVG content documents, `alt` text** | not yet | No style sheet is read, so a block hidden by `display: none` is still in the artifact and generated `::before` text is not. A `<script>`, a `<style>`, a `<template>` and a navigation document are **counted** (**A14**). Attributes are never read as text, so an image's `alt` is absent by that rule |
| **An EPUB navigation document's `page-list` as pagination** | **refusal** | It names the pages of a **print edition** — real identifiers the file writes down, which is why this is the first format where §3's law had to be argued rather than applied. A page record is a page with a width and a height; a label with no geometry can never be validated against anything, so it is a counted region and `pages` stays `[]` |
| **A line break between two CJK characters in an EPUB** | not yet | CSS removes it; this reader turns it into a space. **The widest gap v2-S9 knowingly leaves**, recorded rather than approximated — the correct rule needs a computed `white-space` value and the scripts on both sides, and no style sheet is read |
| **Numeric character references outside an EPUB** | not yet | `&#233;` is well-formed XML that needs no DTD, and v2-S9's reader resolves it. The other **seven** office readers do not resolve it, and **six** of them refuse it by name — `docx`, `xlsx`, `pptx`, `odt`, `ods` and `odp`, the six that reach an entity through `engine_office::xml`'s shared resolver. The seventh is `rtf`, which parses no XML and has no entity to refuse. Widening the shared rule would change what those six shipped `text_code_rule`s do with a document they currently refuse, so unifying them is a decision with six profile-hash moves attached. The *"other six readers"* here counted the six affected and called them the whole remainder, which stopped being the same set when RTF landed at v2-S8; repaired at v2-S13.3 |
| **RTF tables, embedded objects, pictures, fields** | not yet | `\cell` and `\row` are recorded as a paragraph's **terminator** — a fact the stream states — and never as a `TableRecord`, because no detector ran. A `\pict`'s data, an `\object`, a field's instruction and its cached result are each skipped and **counted** |
| **Decoding an RTF `\'hh` above 0x7F** | **refusal** | Its meaning depends on a code page (`\ansicpg1252`, `\ansicpg932`) this reader does not read and carries no table for. Each such byte contributes no character and is counted, because emitting a Latin-1 character would be mojibake presented as a success. Below 0x80 the byte is the same in every ANSI code page and is read |
| **`.odg` drawings, and ODF templates** | not yet | Named separately from the row above because an `.odg`'s `content.xml` really *is* the `<draw:page>` vocabulary v2-S7's reader knows. Detection is **exact**, not prefixed, so a drawing is refused by name rather than producing a plausible artifact for a format nobody decided to support |
| **Text in an ODP drawing shape other than `<draw:frame>` / `<draw:custom-shape>`** | not yet | Those two are what a presentation writes for a text-bearing shape, and naming the set is what makes `OdpLocator::shape` a reproducible position. Text in a `<draw:rect>` or a `<draw:connector>` is **declared** (**A14**) rather than read — no corpus of real `.odp` files was available to measure which elements matter, so the set is read off the specification and kept narrow |
| **Speaker notes, masters and layouts as slide text** | **refusal** | Notes are a second stream and a master's text belongs to every slide, so splicing either in would be a silent **extra** rather than a silent drop — worse, because a consumer cannot tell it from evidence. Both are counted and named (**A14**), and a slide whose title lives only on its master reads as having none |
| **A public confidence float, score, grade, or `is_good`** | **refusal** | Workbench rule 9, `01-CONTRACT.md` §9, and a CI grep (`ci/forbidden-tokens.sh confidence`) that fails the build |
| **Any AGPL dependency** | **refusal** | Forced decision #14. `cargo deny` proves it, and CI proves the proof by flipping a crate to AGPL and requiring rejection |
| **A JVM anywhere** | **refusal** | OpenDataLoader's cost of entry, and the reason its capabilities cannot be borrowed wholesale |
| **A verdict about a claim, a document, or a citation** | **refusal, forever** | The engine owns L0–L2. L3 is the verifier's, and a second verification implementation is the failure this estate is arranged to prevent (`07-VERIFY-BOUNDARY.md`) |
| **Page rasters / DPI screenshots** | not yet | Needs a PDF renderer, and this build depends on no C++ stack and no AGPL code by decision. Declared as a limitation rather than silently absent |

## The one rule that ties both tables together

Everything the engine could not do is **stated** — as a named limitation, a typed absence, or a
counted bucket — rather than guessed at or quietly dropped. A gap is never presented as a success.
If something in the **Cannot** table ever moves to **Can**, it moves with a measurement, not with a
sentence.
