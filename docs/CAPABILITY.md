# What this engine can and cannot do

**These tables describe 0.58.0.** When the workspace version moves, this page moves with it or it
is wrong.

This is the honest inventory — the answer to *"what does ethos-parser actually do today?"* It is not
the roadmap and not a sales pitch. If something is not in the **Can** table, do not promise it.

---

## Can

Everything below runs locally, with no network and no renderer.

| Area | What works | Where |
| --- | --- | --- |
| **Classify** | Sorts a PDF into named reason codes on two axes — does it need OCR, is the layout hard — with per-page counts and three distinct exit codes. No confidence score anywhere | `classify` |
| **Extract (PDF)** | Text runs from a born-digital PDF, each with a locator back into the source bytes, and a box only where font metrics measure one — the run's pen advance over its font's ascent-to-descent envelope, not glyph outlines (contract §5.3) — from the font's own tables, or, for the standard 14, from vendored Adobe AFMs (decision #22) — and only where the run's baseline lies along one of the page's axes, in either direction, and the box lies on the page | `extract` |
| **Standard-14 metrics** | A PDF may name `/BaseFont /Helvetica` with no `/Widths` and no `/FontDescriptor`; §9.6.2.2 permits that because a conforming reader is expected to hold the metrics. This one now does, from vendored AFMs. **10 955 previously ungroundable nodes recover**; documents declaring `font-widths-absent` went 66 → 0. Reading Helvetica's metrics for a font the document calls Helvetica is reading the document; supplying them for Arial is a substitution and stays refused | `extract`, 0.51.0–0.52.0 |
| **Extract (office)** | DOCX, XLSX, PPTX, ODT, ODS, ODP, RTF and EPUB into the same record, each addressed the way its own format addresses itself: `{part, paragraph, run}` for Word, `{part, sheet, row, column}` for a workbook, `{part, shape, paragraph, run}` for a slide, and so on | `extract` |
| **Office pages** | `pages` is always `[]` for office formats. No spreadsheet print range, slide, soft page break or RTF `\page` is ever turned into a page record | — |
| **Grounding** | Emits `ethos.grounding.v1` in both shapes: the paginated 1.0.0 shape for PDFs, and the page-less 1.1.0 shape for office documents, where each element carries its native locator instead of geometry. A DOCX quote extracted here, grounded here, and checked by the sibling verifier comes back `grounded`. **Every PDF span carries `char_start`/`char_end`** — where its text lies in its element's text, in Unicode scalars (not UTF-8 bytes, not UTF-16 units), end exclusive — so Ethos reports no `missing_char_offsets` on those artifacts. It tightens no box: a claim resolves to the same box it did. An artifact past the million-span cap carries neither spans nor offsets, and an office artifact carries neither because the page-less shape admits no spans | `ground` |
| **Grounding check** | A validator whose report is byte-identical to `ethos grounding check`'s for a valid artifact, and has the same verdict, code and path for an invalid one, whose message is its own. Measured against 15 Ethos-owned fixtures — 12 reach an artifact and are compared, and the rest fail closed rather than being skipped — all 16 committed Office documents, and 3,681 mutated artifacts. The source is read only for a valid artifact, as Ethos reads it | `grounding-check` |
| **Markdown / HTML** | Both artifacts carry an anchor map — every byte is either `source` or `syntax` — plus a census of what did not make it. Both are projected from the representation, so office documents project too. **Headings project where the document declares a level** — a PDF's tagged `/H1`..`/H6` and an EPUB's own `<h1>`..`<h6>` — **and, since decision #29, where an untagged PDF's type says so**: a line drawn at least 1.2× the document's body type is read as a level-one heading, marked `inferred_heading` on the representation and declared as `headings-inferred-from-type`, and projects as `#` and `<h1>` under `markdown-blocks-v8` and `html-blocks-v8`. It never runs where the document declares its own structure. **Its false-positive bound and its accuracy band are not measured yet** — they are the next two slices of `docs/28-HEADINGS-SCOPE.md` — so treat an inferred heading as the engine's reading of type, which is what the artifact says it is. ODT/ODS/ODP put the *fact* of a heading on the wire without its level and project as paragraphs rather than guess one; DOCX carries no heading at all, because the reader keeps no `<w:pStyle>` | `markdown`, `html` |
| **Verify** | Shells out to the pinned Ethos CLI and relays its bytes verbatim. The engine does not verify anything itself | `verify` |
| **Overlay** | An annotated copy of a PDF showing what was detected, including a note counting what has **no** box to draw | `overlay` |
| **Tag** | Writes a `/Document`/`/Div` structure tree into a copy of an untagged PDF — one `/Div` per block of the reading-order cut, every element marked computed under `/A << /O /EthosParser /Derivation /Computed /Rule (gutter-columns-v3) >>`, the blocks' text wrapped in marked-content sequences inserted at token boundaries with no byte of the content re-encoded — and reads its own output back before printing it: every run, every binding and every declaration compared against the extract it wrote from. **Fills absence only**: a document that already carries a tree is refused, and so are marked-content ids without one. `extract` on the result binds every run to a computed `Document/Div` address and declares `structure-tree-engine-written`; the text record is unchanged (`docs/23-AUTO-TAGGING-SCOPE.md`) | `tag` |
| **Locate** | Reports **where** a string lies in a representation and nothing else: occurrences as node ids, character offsets into each node's own text in Unicode scalars, and that node's own geometry copied from the record. Exact on scalars — no normalization, no case folding, no whitespace folding — over each block of the reading order, so a match may join runs inside one block and **never across two**; the artifact declares what it searched. **No box is bound tighter than a run**: an occurrence carries the run's own rectangle, never a sub-run or word box ([`22-WORD-BOXES-SCOPE.md`](22-WORD-BOXES-SCOPE.md) refused those on measurement). A string that occurs nowhere is exit 0 and an empty list — there is no verdict, no score, and no exit 1 | `locate`, `mcp`, `packages/` |
| **Adapters** | MCP over stdio, a Python SDK, a Node SDK, and LangChain tools over both. Every locator is minted by the engine, handed back opaque, and re-validated on the way in. No adapter takes a geometry argument | `mcp`, `packages/` |
| **Format detection** | Decided by reading bytes at offset 0, never by file name or extension. Bytes that state no known format are refused by naming what was looked for, and nothing else. A `.csv`, a letter and a log line all get byte-identical stderr | `extract` |
| **Tables** | Row/column model with spans and cell occupancy, four named detection rules (`ruled-rects-v6`, `unruled-align-v1`, `stroke-ruled-v1`, `tagged-tables-v1`), and a cross-check between what the geometry says and what the document's own tags say. Where the two disagree structurally, the rule refuses the grid rather than emitting it. **The ruled rule takes either of two shapes of evidence**: every implied cell covered by ink, or every row and column boundary carried end to end by the rectangle edges lying on it. Neither subsumes the other — a merged cell breaks an interior line, a rules-only grid draws no cell — so either suffices and nothing `-v3` emitted was lost | `extract` |
| **Fabrication** | **0** across the twelve-document labelled set. Measured every run, not asserted | `table-gate-v1.md` |
| **Table accuracy** | Stated as a capability, not an average, re-measured at 0.58.0: the engine reads the tables a document **declares** (162 of 172 gold tables emitted from their tags; combined cell-slot recall **503‰**) and **detects** ruled tables where the producer drew them (geometric macro F1 **69‰**, band 0‰–590‰, median 0‰ — ten of twelve score zero). It emits nothing where neither holds | `table-gate-v1.md` |
| **Fuzzing** | Three `cargo-fuzz` targets covering the PDF entry points and the office router. One campaign ran 3.8M executions under AddressSanitizer and found nothing. Mutation testing damages every PDF fixture six ways and every office package twelve | `fuzz/` |
| **Layout regions** | Every text run says which region of its page the reading-order cut placed it in, 1-based in reading order, under `gutter-columns-v3`. **A region is a column band**: runs stacked within one column share a region however many paragraphs separate them, and the field is absent wherever the cut made no division — which is most pages. It is `Computed` geometry and never a role: no heading, paragraph or section is read from it | `extract` |
| **Layout blocks** | Every text run says which block of its page the cut's horizontal half placed it in, 1-based in reading order, under `gutter-columns-v3`. **A block is a stretch of text separated from its neighbours by whitespace wider than its band's own leading** — it is not a paragraph, a heading or a list item, and no role is read from it (P14). Measured on the one gate document able to carry a real paragraph label: **63.7% of real paragraph breaks at 100% precision**, never firing mid-paragraph across 719 chances. The third it misses is a ceiling rather than a shortfall — 35.1% of real breaks carry no extra leading for any gap rule to see. Absent wherever the rule declined, which includes every page of uniform body text. Its limits — whitespace only, no indent branch, recall measured on one document — are declared on every PDF artifact as `block-subdivision-leading-gap-only` | `extract` |
| **Determinism** | Two runs over one document produce identical bytes, in every format | CI |

## Cannot

Some of these are *not yet*. Others are refusals no version reverses. The middle column says which.

| Claim | Kind | Why |
| --- | --- | --- |
| **"v1 is complete"** | done | Closed on decision #18: v1 states the table capability and the band rather than a single macro. Fabrication is 0, the method is pinned in `table-gate-v1.md`, and the geometric chase stays parked |
| **OCR, or a scan read as extracted text** | not yet — v4 | Recognition is a different class of derivation and needs its own trust ladder. An OCR fingerprint must be provably incomparable with a born-digital parse before that lane can exist |
| **CSV** | refusal, with named reopening conditions | A CSV parse would not fabricate content — every character would be real. Exactly one field would be false: the record would claim the file *is* a CSV when nobody measured that, and there is nowhere in the record to mark a field as asserted rather than measured. Reopens if either the record gains that distinction, or someone builds a format predicate with a measured false-positive rate |
| **Converting office files to PDF to get pages** | refusal | It invents pagination. A DOCX has no pages, and a page on a Word citation measures the printer rather than the document. Not as a fallback, not behind a flag |
| **An EPUB's `page-list` as pagination** | refusal | It names pages of a *print* edition. A page record is a page with a width and a height; a publisher's label about someone else's paper has no geometry to validate against |
| **A paragraph boundary on an untagged page** | not yet | A `region` opens only at a **vertical** gutter, so it separates columns and not paragraphs. The nearest thing is a `block` (Layout blocks, above): it opens at a whitespace gap wider than its band's leading, which catches 63.7% of real paragraph breaks on the one labelled document and misses every paragraph set without extra space. The engine never says a block is a paragraph. Paragraph structure comes from the tag tree or not at all; neither `region` nor `block` stands in for it |
| **A Tagged PDF, or a tag another reader can tell from an author's** | refusal, declared | What `tag` writes is engine-local by decision #23: the derivation lives in an attribute object only this engine reads, so a reader that does not read `/A` sees author structure, and `structure-tree-engine-written` on the artifact is the only other statement. No `/MarkInfo` is written and content outside the sequences is not marked `/Artifact`, so the file is not a Tagged PDF and claims no conformance; a block is where text lies, never what it is, so no `/P`, heading, list or table is ever written (`docs/23-AUTO-TAGGING-SCOPE.md` §9) |
| **Right-to-left text in logical order** | not yet — measured 2026-09-18 | The engine reports characters in the order the page draws them. A producer whose layout engine has resolved bidi writes Hebrew or Arabic in visual order, so the run's text is the logical word reversed — `rtl-hebrew-visual-order` is the fixture, and `extraction.rs` states it. Applying the Unicode bidi algorithm would reorder characters no byte of the page put in that order; a quote copied out of a viewer matches this text, a quote typed in logical order does not. Whether an artifact should declare it is an owner decision (`OPEN-WORK.md` §4) |
| **A folded, normalised or fuzzy `locate` match** | refusal in `-v1`, with named reopening conditions | `locate-scalar-exact-v1` is exact on Unicode scalars. A case-insensitive, NFC-normalised or whitespace-folded search is a **`-v2` rule with its own id**, never a flag on this one: a flag would make two answers under one rule id, and the id is what makes two artifacts comparable. The same holds for a match crossing a block boundary, and for searching a table cell's concatenated text — the next `-v2` candidate (`docs/26-LOCATE-SCOPE.md` §4.1, §12) |
| **A word box, or any box tighter than a run** | refusal, on measurement | `locate` echoes the run's own rectangle for an occurrence inside it. Sub-run boxes were refused on measurement in `docs/22-WORD-BOXES-SCOPE.md` §7, and an occurrence is not a place to reintroduce them |
| **A confidence score, grade, or `is_good` field** | refusal | Enforced by a CI grep that fails the build |
| **A verdict about a claim or a citation** | refusal, permanent | The engine owns extraction and grounding. Verification belongs to the verifier, and a second verification implementation is exactly the failure this project is arranged to prevent |
| **Any AGPL dependency, or a JVM** | refusal | `cargo deny` enforces the licence rule, and CI proves the proof by flipping a crate to AGPL and requiring rejection |
| **A benchmark table comparing this to other parsers** | refusal | Headline numbers in this space are publisher-owned. The same tool has scored 0.000 and 0.693 on tables under two publishers, differing only by invocation flags |
| **Page rasters / screenshots** | not yet | Needs a PDF renderer, and this build depends on no C++ stack and no AGPL code by decision |
| **Office embedded images, audio and video** | not yet | Counted and declared by every reader, never decoded. A media part has no text, no address a citation could bind to, and no geometry |
| **RTF tables, pictures, embedded objects and fields** | not yet | `\cell` and `\row` are recorded as a paragraph terminator, which is a fact the file states, and never as a table, because no detector ran |
| **Decoding an RTF `\'hh` byte above 0x7F** | refusal | Its meaning depends on a code page this reader does not read. Emitting a Latin-1 character instead would be mojibake dressed up as success. The byte is counted instead |
| **EPUB stylesheets, scripts, media overlays and `alt` text** | not yet | No stylesheet is read, so text hidden by `display: none` is still in the record and generated text is not. Attributes are never read as text |
| **A line break between two CJK characters in an EPUB** | not yet | CSS removes it; this reader turns it into a space. The correct rule needs a computed `white-space` value and the scripts on both sides |
| **`.odg` drawings and ODF templates** | not yet | Format detection is exact rather than prefixed, so a drawing is refused by name rather than producing a plausible artifact for a format nobody decided to support |
| **Speaker notes, slide masters and layouts as slide text** | refusal | Notes are a second stream and a master's text belongs to every slide. Splicing either in would be a silent *addition* to the evidence, which is worse than a silent drop because a consumer cannot tell it apart from the real thing. Both are counted instead |
| **Text in ODP shapes other than frames and custom shapes** | not yet | Those two are what a presentation writes for text. The set is read off the specification and kept narrow, because no corpus of real `.odp` files was available to measure which others matter |

## The rule underneath both tables

Everything the engine could not do is **stated** — as a named limitation, a typed absence, or a
counted bucket. A gap is never presented as a success. When something moves from **Cannot** to
**Can**, it moves with a measurement, not with a sentence.
